# STALKER — Путь по Кордону

Браузерный прототип текстовой RPG в сеттинге STALKER. Проект рассчитан на GitHub Pages, смартфоны и ноутбуки; основной интерфейс ориентирован на горизонтальную ориентацию. Игровые иллюстрации и музыка подключаются по внешним ссылкам, поэтому локальный архив не содержит копий изображений или музыкальных записей.

## Запуск

Открой папку проекта в терминале и запусти локальный сервер:

```bash
python -m http.server 8000
```

Перейди на `http://localhost:8000`. Не запускай проект двойным нажатием по HTML: браузер может блокировать ES-модули при `file://`.

## Публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub.
2. Загрузи в корень репозитория содержимое этой папки: `index.html`, `styles.css`, `src/`, `assets/`, `manifest.webmanifest`, `sw.js` и остальные файлы.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch**, ветку `main` и каталог `/ (root)`.
5. После публикации открой адрес GitHub Pages. Для установки на телефон используй «Добавить на главный экран».

## Что реализовано

- Главное меню, статистика аккаунта, настройки и выбор персонажей.
- КПК-регистрация: имя, дата рождения, рост, вес, характер, биография и портрет.
- 18 портретов: 6 одиночек, 4 бандита, 4 военных и портреты четырёх ключевых NPC — Сидоровича, Волка, Кефира и Дзержинского. Также можно загрузить собственное изображение.
- Стартовые фракции и точки появления: Одиночки — Деревня новичков; Бандиты — АТП; Военные — Южный блокпост.
- Стартовый бюджет 2 500 RU, каталог с сортировкой по цене и сеточный инвентарь с ограничением 50 кг.
- КПК: карта Кордона, статистика, журнал сообщений, задания и контакты.
- Отдельная вкладка **Радио** с 10 настоящими музыкальными композициями. Выбор песни запускает встроенный YouTube-плеер; ссылки на оригинальные страницы можно открыть отдельно.
- Диалоги Сидоровича, Волка, Кефира и Дмитрия Дзержинского.
- Обыск локаций, случайный лут, тайники и восстановление запасов со временем.
- Соседние переходы, разведка биноклем, перемещение отрядов и встречи с мутантами.
- Упрощённый пошаговый бой, сон, потребности, радиация, гравитационные аномалии и мини-игра поиска артефактов.
- Локальный генератор ответов по ключевым словам, ситуации и случайным вариантам.
- Автосохранение в браузере и экспорт/импорт сохранений JSON.

## Радио и внешняя музыка

Музыка не скачивается и не вшивается в архив. Список `RADIO_TRACKS` находится в `src/data/catalog.js` и хранит названия, исполнителей и YouTube video ID. Плеер загружается через `youtube-nocookie.com` только после нажатия пользователя. Автовоспроизведение при открытии игры отключено. Для воспроизведения требуется интернет; отдельное видео может быть недоступно в некоторых регионах или из-за настроек правообладателя. В этом случае используй кнопку-ссылку для открытия трека на YouTube.

Список можно расширять: добавь объект `{ id, title, artist, videoId, label, era }` в `RADIO_TRACKS`. `videoId` — часть URL после `v=` в обычной ссылке YouTube.

## Архитектура

```text
index.html                  точка входа
styles.css                  адаптивная тема и стили
manifest.webmanifest        PWA-манифест
sw.js                       офлайн-кэш оболочки приложения
src/
  main.js                   экран, обработчики событий и состояние
  core/storage.js           localStorage, экспорт и импорт
  data/catalog.js           предметы, изображения, локации, NPC, портреты и радио
  systems/
    game-clock.js           игровые дата и время
    inventory.js            вес, сетка, покупка и использование предметов
    world.js                мир, лут, репутация, задания и перемещения
    combat.js               боевые правила
    action-engine.js        разбор текстовых команд
  ui/views.js               HTML-представления экранов
assets/
  icons/                    локальная SVG-иконка PWA
```

Модули систем не импортируют UI. Каталог предметов, NPC, портретов, локаций и треков редактируется в `src/data/catalog.js`. Для правил инвентаря используй `src/systems/inventory.js`, для мира — `world.js`, для боёвки — `combat.js`, для отображения — `src/ui/views.js` и `styles.css`.

## Игровое время

При создании персонажа внутриигровая дата начинается с 15 апреля, часы берутся из локального времени устройства. Переходы, сон и бой добавляют игровое время.

## Команды, распознаваемые строкой действий

- `осмотреться`, `что вокруг`, `обстановка` — описание текущей локации;
- `осмотреть биноклем Элеватор` — разведка соседней локации без перехода (нужен бинокль);
- `карта`, `куда идти` — открыть карту;
- `инвентарь`, `рюкзак` — открыть рюкзак;
- `обыскать местность`, `обыскать труп`, `найти тайник` — поиск лута;
- `поговорить с Волком`, `спросить Сидоровича`, `Кефир` — начать диалог, если NPC находится здесь;
- `артефакт`, `детектор`, `сигнал` — начать мини-игру при наличии детектора и аномалии;
- `болт`, `проверить аномалию` — отметить безопасный проход при наличии болтов;
- `спать`, `отдохнуть` — открыть выбор длительности сна.

Свободный текст пока обрабатывается локальным правиловым движком: он ищет русские ключевые слова, учитывает состояние мира и выбирает случайные формулировки. Внешняя языковая модель не подключена.

## Сохранения и перенос

Данные хранятся в `localStorage` браузера и не синхронизируются автоматически. Для переноса используй **Настройки → Скачать сохранение**, а на другом устройстве — **Загрузить сохранение**.

## Внешние материалы

Игровые фоны, карта, предметы, портреты и иконки NPC загружаются с URL, заданных в `src/data/catalog.js`. Музыкальные композиции транслируются через встроенный YouTube-плеер. Локально остаются только код, стили и SVG-иконка PWA. При отсутствии интернета или блокировке стороннего источника соответствующее изображение/музыка может быть недоступна; для изображений предусмотрены текстовые fallback-варианты.

Внешние визуальные и аудиоматериалы остаются собственностью их правообладателей. MIT-лицензия относится к коду прототипа и не передаёт права на изображения или музыку.

## Известные ограничения

- Нет настоящей регистрации, облачной синхронизации, мультиплеера или серверной базы.
- Радио использует сторонний YouTube embed и требует интернета; браузер может блокировать автоматический старт, поэтому воспроизведение запускается по клику.
- Некоторые изображения на сторонних сайтах могут быть перемещены или удалены.
- Бой, мутанты и свободный текст — прототипные системы, рассчитанные на дальнейшее расширение.
- Карта использует предоставленную картинку и условные координаты меток.
