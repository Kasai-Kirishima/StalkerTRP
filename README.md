# STALKER — Путь по Кордону · версия 2.5.2

Браузерная RP/RPG-игра в сеттинге Кордона. Интерфейс рассчитан на ноутбуки и мобильные устройства; КПК открывается отдельным полноэкранным слоем с локальной текстурой, которая заполняет экран.

## Запуск

Требуется Node.js для тестов, а для локального запуска достаточно Python: 

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Не запускай через `file://`: браузер может блокировать ES-модули.

## Что есть в игре

- Три фракции: одиночки, бандиты и военные; у каждой свои отношения, территории, NPC и стартовая экипировка.
- Случайные жители Деревни новичков, военные на блокпостах и бандиты на АТП. Их имена, клички и распорядок генерируются при новой игре; в активном сохранении личности остаются постоянными.
- Локальные портреты и полнофигурные внешности NPC, подобранные парами по фракциям. Для бандитских внешностей 4 и 5 используется общий портрет `banditicon4i5.webp`, как задумано в исходном наборе.
- Знаки фракций и рангов, а также иконки журнала заданий. Все эти изображения загружаются из `assets/`.
- Свободные диалоги с контекстными ответами. У бандитов отдельная манера речи с феней и жаргоном; варианты реплик различаются по персонажам и ситуации.
- Торговля с Сидоровичем, Шнурком, снабженцами и встреченными сталкерами. Окно обмена открывается кнопкой или командами вроде «торговать», «купить», «продать». Валюта — Купоны.
- Стартовый набор включает лёгкую броню и простой противогаз, соответствующие выбранной фракции и статусу новичка.
- Инвентарь-сетка с учётом габаритов и веса, двумя слотами основного оружия, слотами пистолета, ножа, брони и противогаза, а также четырьмя быстрыми слотами. Броня занимает несколько клеток и отображается крупной иллюстрацией с обрезкой по верхней части костюма.
- Двухоконный обыск с перетаскиванием, действиями «Забрать всё» и «Сложить всё», лутом из тайников, контейнеров и останков противников. Есть личные хранилища и разрушаемые ящики.
- Карта Кордона с переходами, временем пути и карточками локаций. Места и цели отображаются в карточке точки.
- Квесты «Колбаска для Пуделя», «Новая аномалия» и освобождение пленных на АТП.
- Аномалии Трамплин, Воронка и Карусель, обнаружение артефактов и детектор «Медведь».
- Предметы: артефакт «Каменный цветок», плавленый сырок «Янтарь», счётчик радиации «Припять», экипировка, оружие и расходники.
- RP-действия: бартер, угрозы и поддразнивание, анекдоты, отдых, готовка у костра, кража, музыка с устройства и интерактивное освещение.
- КПК с картой, заданиями, контактами, энциклопедией и помощью. Энциклопедия пополняется по мере исследования мира.
- Звуковые сигналы интерфейса, торговли, опасности, аномалий и успешных действий. Их громкость регулируется в настройках.
- Сохранения хранятся в браузере; их можно экспортировать и импортировать JSON-файлом.

## Музыка

Старые интернет-радиостанции, сетевые ссылки, встраиваемые видеоплееры и радиокнопки из сцены удалены. Вместо этого в КПК находится локальный плеер: выбери на своём устройстве папку `Music` или несколько аудиофайлов. Поддерживаются MP3, M4A, OGG, WAV, FLAC и AAC. Файлы воспроизводятся в браузере и не отправляются на сервер. После перезапуска страницы папку потребуется выбрать повторно.

Аудиозаписи из пользовательского архива в распространяемый ZIP не включены: музыкальные произведения остаются на устройстве пользователя.

## Развёртывание на GitHub Pages

1. Создай репозиторий и загрузи в корень проекта содержимое этой папки.
2. В GitHub открой **Settings → Pages**.
3. Выбери **Deploy from a branch**, ветку `main` и каталог `/ (root)`.

## Структура

```text
index.html
styles.css
sw.js
manifest.webmanifest
assets/
  npc/Vneska/       портреты и полнофигурные внешности NPC
  insignia/         знаки фракций и званий
  quests/            иконки заданий
  images/            карта, фон КПК и локаций
src/
  main.js            интерфейс и действия игрока
  core/storage.js    сохранения
  data/catalog.js    предметы, NPC, фракции, локации и изображения
  systems/           мир, диалоги, бой, инвентарь, музыка и звук
  ui/views.js        разметка экранов
tests/               smoke-тесты
```

## Проверка

```bash
npm test
```

Тесты проверяют игровые системы, локальные изображения, соответствия портретов и внешностей, иконки заданий, локальный музыкальный плеер, торговлю, диалоги и бой.

## Известные ограничения

- Игра является локальным браузерным прототипом без мультиплеера и облачной синхронизации.
- Локальная музыка не хранится в игровом сохранении; после обновления страницы пользователь выбирает файлы снова.
- Физические анимации и визуальные эффекты боёв/аномалий упрощены и реализованы средствами интерфейса.


## Версия 2.5.2 — изображения костюмов в инвентаре

- Подрезаны прозрачные поля у вертикальных спрайтов брони, чтобы сама экипировка занимала больше места в своей ячейке.
- В инвентаре костюмы вписываются целиком по пропорциям (`object-fit: contain`): плечи, нижняя часть и контур не срезаются.
- Размеры сетки предметов сохранены: броня по-прежнему занимает свои 2×3 или 3×3 клетки.
