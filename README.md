# STALKER — Путь по Кордону

Локальный браузерный прототип текстовой RPG в сеттинге STALKER. Проект рассчитан на публикацию на GitHub Pages и работу в браузере телефона или ноутбука. Основной макет ориентирован на горизонтальную ориентацию, но интерфейс адаптируется и к вертикальному экрану.

## Запуск

**Быстрый способ:** открой `index.html` через локальный сервер. Не рекомендуется запускать двойным нажатием по HTML-файлу: браузеры могут ограничивать ES-модули и PWA-функции при `file://`.

```bash
# В папке проекта
python -m http.server 8000
```

Открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создай пустой репозиторий на GitHub.
2. Загрузи в корень репозитория всё содержимое этой папки: `index.html`, `styles.css`, `src/`, `assets/`, `manifest.webmanifest`, `sw.js` и остальные файлы.
3. Открой **Settings → Pages**.
4. Выбери источник **Deploy from a branch**, ветку `main` и каталог `/ (root)`.
5. Сохрани настройки и открой адрес GitHub Pages, который покажет GitHub.

Для установки как PWA открой опубликованную страницу в браузере телефона и используй пункт «Добавить на главный экран». Service Worker и офлайн-кэш работают по HTTPS (GitHub Pages подходит).

## Что уже реализовано

- Главное меню с фоном, аккаунтом, настройками и переходом к персонажам.
- Создание и выбор нескольких персонажей; портрет можно выбрать из набора или загрузить с устройства.
- Фракции: Одиночки, Бандиты и Военные. Стартовые точки: Деревня новичков, АТП и Южный блокпост.
- КПК с датой, временем, картой Кордона, статистикой, журналом сообщений, заданиями и контактами.
- Стартовый бюджет **2 500 RU**; предметы в магазине отсортированы по возрастанию стоимости.
- Инвентарь-сетка с размерами предметов, весом и ограничением **50 кг**.
- Четыре персонажа с отдельными диалогами: Сидорович, Волк, Кефир и Дмитрий Дзержинский.
- Поиск припасов в локациях и случайный обыск условных тел; лут обновляется спустя 180 игровых минут.
- Перемещение по соседним локациям, шанс встречи со слепыми псами и перемещение NPC-отрядов.
- Упрощённая пошаговая боевая система: атака, защита и отступление.
- Сон, базовые показатели здоровья/голода/жажды/радиации, расходники и броня.
- Мини-игра поиска артефактов с детектором «Отклик» и проверка локальных аномалий болтами.
- Локальная генерация ответа по ключевым словам, текущей локации и случайным фразам.
- Десять оригинальных процедурно созданных атмосферных зацикленных звуков в `assets/audio/`.
- Автосохранение в браузере, экспорт и импорт сохранения JSON.

## Архитектура

```text
index.html                  точка входа
styles.css                  все стили и адаптивная сетка
manifest.webmanifest        PWA-манифест
sw.js                       офлайн-кэш приложения
src/
  main.js                   связывает экран, события и состояние
  core/
    storage.js              localStorage, экспорт/импорт
  data/
    catalog.js              единый каталог предметов, локаций, NPC, фракций и заданий
  systems/
    game-clock.js           игровые дата и время
    inventory.js            вес, сетка, покупка и использование предметов
    world.js                мир, лут, репутация, задания, сон и перемещения
    combat.js               бой
    action-engine.js        распознавание текстовых команд
    audio.js                управление фоновой дорожкой
  ui/
    views.js                HTML-представления экранов
assets/
  audio/                    10 локальных WAV-дорожек
  icons/                    PWA-иконка
  images/                   место для локальных изображений проекта
```

Модули систем не импортируют UI. Если нужно изменить правила предметов — редактируй `src/data/catalog.js` и `src/systems/inventory.js`. Для маршрутов и выпадения лута — `world.js`. Для атак — `combat.js`. Для внешнего вида — `styles.css` и `ui/views.js`.

## Игровое время

При создании персонажа внутриигровая дата начинается с **15 апреля**, а часы берутся из локального времени устройства. Действия вроде перехода, сна и боя добавляют игровое время. При открытии сохранения календарь учитывает прошедшие реальные дни.

## Команды, распознаваемые строкой действий

Примеры фраз:

- `осмотреться`, `что вокруг`, `обстановка` — описание текущей локации;
- `осмотреть биноклем Элеватор` — разведка соседней локации без перехода (нужен бинокль);
- `карта`, `куда идти` — открыть карту;
- `инвентарь`, `рюкзак` — открыть рюкзак;
- `обыскать местность`, `обыскать труп`, `найти тайник` — поиск лута;
- `поговорить с Волком`, `спросить Сидоровича`, `Кефир` — начать диалог, если NPC находится здесь;
- `артефакт`, `детектор`, `сигнал` — начать мини-игру при наличии детектора и аномалии;
- `болт`, `проверить аномалию` — отметить безопасный проход при наличии пачки болтов;
- `спать`, `отдохнуть` — открыть выбор длительности сна;
- `атаковать`, `стрелять` — вступить в бой или атаковать текущего противника;
- `вода`, `попить`, `поесть`, `лечиться`, `антирад` — использовать подходящий предмет из инвентаря;
- `задания`, `статистика`, `отряд`, `патруль` — открыть раздел или получить сведения.

В пачке болтов 10 отдельных использований; пачка патронов также содержит несколько выстрелов, а не расходуется целиком за один выстрел.

Свободный текст не отправляется во внешний ИИ-сервис. Сейчас это локальный rule-based движок: ищет русские ключевые слова, учитывает текущее состояние мира и добавляет случайные варианты ответа. Позже его можно заменить отдельным API-модулем, не затрагивая инвентарь, сохранения и карту.

## Сохранения и перенос

Сохранение находится в `localStorage` браузера и не синхронизируется автоматически между устройствами. Для переноса открой **Настройки → Скачать сохранение**, затем на втором устройстве выбери **Загрузить сохранение**. Сохраняй резервную копию после важных игровых изменений.

## Изображения и сторонние материалы

В `src/data/catalog.js` сохранены адреса изображений, предоставленные автором проекта (в основном STALKER Wiki/Fandom и Steam Community). В этой сборочной среде не удалось скачать эти изображения локально, поэтому они загружаются с исходных сайтов. Для работы интерфейса они не обязательны: при ошибке загрузки показываются текстовые/графические заглушки. При отсутствии интернета изображения могут быть недоступны.

Аудиофайлы в `assets/audio/` сгенерированы специально для этого прототипа и не являются треками из игр STALKER. Код проекта распространяется по MIT License; права на внешние изображения остаются у их владельцев. Перед публичным коммерческим релизом проверь лицензии и условия использования каждого стороннего изображения.

## Известные ограничения прототипа

- Нет настоящей регистрации, сетевого аккаунта, мультиплеера или облачной синхронизации.
- Реакции на свободный текст работают по словарю ключевых слов, а не через полноценную языковую модель.
- Бой и поведение мутантов упрощены для первой версии; это каркас для расширения.
- Карта использует предоставленное изображение и условные координаты меток, а не точную навигационную геометрию.
- Изображения STALKER Wiki/Fandom требуют сети и могут перестать открываться при изменении источника.
- Кнопка «Выход» объясняет ограничение браузера: веб-страница не может закрыть вкладку, открытую пользователем.
