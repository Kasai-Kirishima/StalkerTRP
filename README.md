# STALKER — Путь по Кордону

Браузерный прототип текстовой RPG в сеттинге STALKER. Проект рассчитан на GitHub Pages, смартфоны и ноутбуки; основной интерфейс ориентирован на горизонтальную ориентацию. Большинство иллюстраций и вся музыка загружаются по внешним URL. Чистая карта Кордона, предоставленная пользователем, лежит локально в `assets/images/cordon-clean.webp`, чтобы точки карты всегда совпадали с разметкой.

## Запуск

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Не запускай через `file://`: браузер может заблокировать ES-модули.

## Публикация на GitHub Pages

1. Создай пустой репозиторий GitHub.
2. Загрузи в корень репозитория всё содержимое этой папки.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch**, ветку `main` и каталог `/ (root)`.
5. Для установки на телефон открой опубликованный сайт и выбери «Добавить на главный экран».

## Системы прототипа

- Главное меню, аккаунт, настройки и выбор персонажа.
- КПК-анкета: имя, дата рождения, рост, вес, характер, биография и внешний/локальный портрет.
- 18 портретов: 6 одиночек, 4 бандита, 4 военных и 4 ключевых NPC.
- Три фракции и точки старта: Деревня новичков, АТП и Южный блокпост.
- Стартовый бюджет 2 500 RU; магазин сортирует предметы по цене.
- Инвентарь-сетка с ограничением 50 кг.
- КПК: карта с кликабельными прозрачными метками, статистика, сообщения, задания, контакты, радио, отдельный фоновый плеер и торговля.
- NPC: Сидорович, Волк, Кефир, Дзержинский, торговцы Шнурок и Каптёрка (квартирмейстер военных).
- Обыск локаций, случайный лут, тайники, восстановление запасов, отряды и соседние переходы.
- Бинокль для разведки соседних локаций.
- Бой с NPC, слепыми псами и мутантом Плоть; трофей «Глаз плоти», сон, потребности, радиация, гравитационные аномалии и поиск артефактов.
- Торговля: покупка и продажа предметов, склады постоянных продавцов и четырёх бродячих торговцев, перемещающихся по Кордону.
- Локальный генератор реакций на текстовые действия.
- Автосохранение в браузере и экспорт/импорт сохранения JSON.

## Радио и фоновый плеер

В музыкальном каталоге **65 композиций**: три независимые радиостанции по 20 композиций (в сумме 60) и пять дополнительных записей. На разных базах композиции не повторяются; порядок на радио случайный, ручной выбор и пропуск в эфире недоступны. «Владимирский централ» доступен только на радио АТП и в личном плеере.

Во вкладке **«Плеер»** можно выбрать композицию из библиотеки, поставить паузу, продолжить, переключить назад/вперёд или остановить. Музыка использует YouTube IFrame API и остаётся запущенной при переходе между вкладками КПК. После перезагрузки страницы браузер не включает музыку сам — требуется действие пользователя.

Музыкальная библиотека заменена по последнему списку исполнителей пользователя. Все композиции True Stalker удалены; в трёх базах по 20 непересекающихся треков, личный плеер содержит весь каталог. Возраст релиза не используется как фильтр, поскольку пользователь отдельно запросил ряд классических исполнителей и песен.

| База | Станция | Частота | Очередь |
|---|---|---:|---:|
| Деревня новичков | Радио Деревни новичков | 100.7 FM | 20 композиций |
| АТП | Радио АТП | 101.3 FM | 20 композиций |
| Южный блокпост | Радио Южного блокпоста | 103.1 FM | 20 композиций |

Для прослушивания требуется интернет. Отдельные видеозаписи могут быть недоступны из-за региональных или авторских ограничений. Браузер может приостанавливать скрытое воспроизведение в энергосберегающем режиме.

## Карта и внешние ссылки

Чистая карта пользователя хранится в `assets/images/cordon-clean.webp`. Поверх неё отображаются увеличенные полупрозрачные серые круги диаметром 30 px (метка игрока — 34 px), удобные для нажатия на телефоне. Нажатие открывает окно с названием, кратким описанием, отметкой опасности и временной заглушкой фотографии; кнопка перехода активна только для соседней локации. Восточный туннель ЖД расположен выше и правее локомотива, подземный переход — правее и немного выше вагончика.

Изображения локаций, элементов интерфейса, NPC и предметов (кроме предоставленной карты) загружаются непосредственно по URL. Для меню, интерфейса КПК, локаций, портретов, мутантов, еды, медицины и снаряжения добавлены резервные источники. Если первичное изображение не загрузится, интерфейс попробует показать резервное, а затем текстовую/эмодзи-заглушку.

Для отдельных предметов и портретов сохранены присланные исходные картинки, потому что точную независимую замену для каждого отдельного значка найти надёжно не удалось. В таких случаях используется тематический внешний резервный атлас соответствующей категории. Поэтому это рабочая схема с резервами, но не обещание, что каждый отдельный значок имеет уникальную зеркальную копию.

Полный реестр ссылок и музыкальный плейлист см. в [`ASSETS.md`](ASSETS.md).

## Архитектура

```text
index.html                  точка входа
styles.css                  адаптивная тема и стили
manifest.webmanifest        PWA-манифест
sw.js                       офлайн-кэш оболочки приложения
src/
  main.js                   экран, обработчики и состояние
  core/storage.js           localStorage, экспорт и импорт
  data/catalog.js           предметы, изображения, локации, NPC, портреты и музыка
  systems/
    game-clock.js           игровые дата и время
    inventory.js            вес, сетка, покупка и использование предметов
    world.js                мир, лут, репутация, задания и отряды
    combat.js               правила боя
    music.js                постоянный YouTube-плеер
    action-engine.js        разбор текстовых команд
  ui/views.js               представления экранов
assets/icons/               SVG-иконка PWA

```

Системные модули не импортируют UI. Каталог игровых данных находится в `src/data/catalog.js`.

## Игровое время

Внутриигровая дата начинается с 15 апреля, часы берутся из локального времени устройства. Переходы, сон и бой продвигают игровое время.

## Цикличные поручения Сидоровича

Чтобы получить работу, подойди к Сидоровичу в подвале и в диалоге выбери «Работа», «Задания», «Квесты» или «Поручения». После этого появится кнопка случайного поручения. Одновременно активно только одно цикличное задание; после сдачи следующую работу можно получить через 2 игровых часа.

Доступны три поручения:

- **Крутить хвосты собакам** — принести 5 хвостов обычных слепых псов. При победе над слепым псом хвост может выпасть с вероятностью 72%; псевдособаки в игре не считаются. Награда: 850 RU.
- **Коллектор** — игра случайно выбирает одного бродячего сталкера-должника. Найди его по текущей отметке местоположения, поговори с ним и вернись к Сидоровичу. Награда: 600 RU.
- **Ловля Медузы** — найти артефакт «Медуза» и принести его Сидоровичу. Награда: 1100 RU.

Поручение отображается в КПК → Задания. Сдача и выплата происходят при разговоре с Сидоровичем через кнопку «Сдать поручение». За выполненное поручение начисляется +5 рейтинга.

## Примеры распознаваемых действий

- `осмотреться`, `что вокруг`, `обстановка` — описание текущей локации;
- `осмотреть биноклем Элеватор` — разведка соседней локации;
- `карта`, `куда идти` — открыть карту;
- `инвентарь`, `рюкзак` — открыть рюкзак;
- `обыскать местность`, `обыскать труп`, `найти тайник` — поиск лута;
- `поговорить с Волком`, `спросить Сидоровича`, `Кефир` — диалог с доступным NPC;
- `артефакт`, `детектор`, `сигнал` — мини-игра поиска при наличии детектора;
- `болт`, `проверить аномалию` — попытка найти безопасный проход;
- `спать`, `отдохнуть` — выбор длительности сна.

Свободный текст обрабатывается локальным правиловым движком по ключевым словам и текущей ситуации. Внешняя языковая модель не подключена.

## Сохранения и перенос

Данные хранятся в `localStorage` конкретного браузера и автоматически между устройствами не синхронизируются. Для переноса используй **Настройки → Скачать сохранение** и **Загрузить сохранение** на другом устройстве.
