# STALKER — Путь по Кордону · версия 3.4.1

Браузерная RP/RPG-игра в сеттинге Кордона. Интерфейс рассчитан на ноутбуки и мобильные устройства; КПК открывается отдельным полноэкранным слоем с локальной текстурой, которая заполняет экран.

## Запуск

Требуется Node.js для тестов, а для локального запуска достаточно Python: 

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`. Не запускай через `file://`: браузер может блокировать ES-модули.

## Обновление 3.4.1 — исправление главного меню и новая система внешности NPC

- Исправлен критический сбой стартового экрана: главный модуль вызывал `mountStalker3D` и `disposeStalker3D`, не импортируя их из WebGL-рендерера. Из-за этого приложение падало при первом рендере до показа меню.
- Добавлен запускной интеграционный тест: он импортирует основной модуль, проверяет главное меню и нажимает «Играть», подтверждая переход к созданию персонажа без `ReferenceError`.
- Угловатые процедурные манекены больше не используются как основной визуал людей. В 3D-сцене NPC используют прозрачный атлас из 16 полнофигурных изображений, уже находившихся в ресурсах игры; варианты распределены по фракциям и поворачиваются лицом к игроку.
- Для новых персонажных спрайтов добавлены прозрачность, тени у ног и лёгкое движение в покое. Масштаб приведён примерно к росту человека. При недоступности атласа остаётся процедурная запасная модель.
- Исправлен горизонтальный знак угла поворота NPC: персонажи и участники столкновений теперь корректно ориентируются на позицию игрока.
- Исправлено чрезмерное влияние текстурного атласа на цвет материалов: фактура больше не так сильно загрязняет оттенки кожи и одежды, сохраняется мягкая неоднородность поверхностей.
- Добавлен локальный RGBA-атлас внешности NPC в офлайн-кеш Service Worker; версия кеша повышена, чтобы браузер не продолжал использовать старые файлы.
- Музыкальные файлы, каталог, импорт аудио, плеер и музыкальное радио остаются удалёнными. Игровые звуковые эффекты сохранены.

## Что есть в игре

- Три фракции: одиночки, бандиты и военные; у каждой свои отношения, территории, NPC и стартовая экипировка.
- Случайные жители Деревни новичков, военные на блокпостах и бандиты на АТП. Их имена, клички и распорядок генерируются при новой игре; в активном сохранении личности остаются постоянными.
- Локальные портреты и полнофигурные внешности NPC, подобранные парами по фракциям. Для бандитских внешностей 4 и 5 используется общий портрет `banditicon4i5.webp`, как задумано в исходном наборе.
- Знаки фракций и рангов, а также иконки журнала заданий. Все эти изображения загружаются из `assets/`.
- Свободные диалоги с контекстными ответами. У бандитов отдельная манера речи с феней и жаргоном; варианты реплик различаются по персонажам и ситуации.
- Торговля с Сидоровичем, Шнурком, снабженцами и встреченными сталкерами. Окно обмена открывается кнопкой или командами вроде «торговать», «купить», «продать». Валюта — Купоны.
- Стартовый набор включает лёгкую броню и простой противогаз, соответствующие выбранной фракции и статусу новичка.
- Инвентарь-сетка с учётом габаритов и веса, двумя слотами основного оружия, слотами пистолета, ножа, брони и противогаза, а также четырьмя быстрыми слотами. Броня занимает несколько клеток и отображается крупной иллюстрацией целиком, с сохранением пропорций и без обрезания нижней части костюма.
- Двухоконный обыск с перетаскиванием, действиями «Забрать всё» и «Сложить всё», лутом из тайников, контейнеров и останков противников. Есть личные хранилища и разрушаемые ящики.
- Карта Кордона с точками текущего положения и целей заданий; названия и линии маршрутов на самой карте скрыты.
- Квесты «Колбаска для Пуделя», «Новая аномалия» и освобождение пленных на АТП.
- Аномалии Трамплин, Воронка и Карусель, обнаружение артефактов и детектор «Медведь».
- Предметы: артефакт «Каменный цветок», счётчик радиации «Припять», экипировка, оружие и расходники. «Янтарь» не является предметом: он может лишь изредка упоминаться в разговоре.
- RP-действия: персональный бартер, угрозы и поддразнивание, анекдоты, отдых, готовка у костра, кража и интерактивное освещение.
- КПК с картой, заданиями, контактами, энциклопедией и помощью. Энциклопедия пополняется по мере исследования мира.
- Звуковые сигналы интерфейса, торговли, опасности, аномалий и успешных действий. Их громкость регулируется в настройках.
- Сохранения хранятся в браузере; их можно экспортировать и импортировать JSON-файлом.

## Общение с NPC и генеративный ИИ

По умолчанию диалоги работают локально: движок распознаёт темы, хранит контекст отдельного собеседника, даёт проверенные подсказки по соседним переходам и сохраняет запасные ответы, если сообщение непонятно. Локальный режим не обращается к сети и работает офлайн.

Для генеративной модели можно подключить свой сервер-прокси. Игра отправляет ему имя/роль/фракцию NPC, текущую локацию, доступные выходы, активные задания и последние реплики. Настроить адрес можно в **Настройки → Общение с NPC · ИИ**. В браузер нельзя вставлять API-ключ: он должен храниться только в переменных среды сервера.

В проект добавлен пример прокси без дополнительных npm-зависимостей (`server/npc-ai-proxy.mjs`). Он ожидает OpenAI Chat Completions-совместимый провайдер. Запуск на Node.js 18+:

```bash
# Linux / macOS
cp .env.example .env
# Windows PowerShell
Copy-Item .env.example .env
# заполни LLM_API_URL, LLM_API_KEY и LLM_MODEL в .env
npm run ai-proxy
```

Затем в настройках игры укажи `http://127.0.0.1:8787/npc-chat` (для локального запуска с `http://localhost:8000`). Для сайта на HTTPS прокси также должен быть доступен по HTTPS, а его домен нужно добавить в `ALLOWED_ORIGINS`. Сервер слушает только localhost; при размещении игры не на localhost укажи её origin в `ALLOWED_ORIGINS`. Если сервер недоступен или не настроен, игра оставляет локальный ответ. Торговля, квесты и точные маршруты всегда обрабатываются игровым движком, а не генеративной моделью.

## Известные ограничения

- Игра является локальным браузерным прототипом без мультиплеера и облачной синхронизации.
- Музыкальные файлы, каталог, плеер, импорт аудио и музыкальное радио удалены. Игровые звуковые эффекты остаются отдельной функцией.
- Текущий WebGL-рендерер использует процедурную геометрию окружения и предметов. Для людей в сцене сейчас применяются полнофигурные прозрачные 2D-спрайты, размещённые как билборды в 3D-пространстве; это заметно качественнее старых угловатых манекенов, но ещё не полноценные скелетные 3D-модели. У NPC пока нет скелетной анимации ходьбы и отдельных ракурсов спрайта.
- Физические анимации и визуальные эффекты боёв/аномалий упрощены и реализованы средствами интерфейса.

- Иконки оружия показываются в нижней части игровой сцены как вид от первого лица; на правой стороне ствол направлен к центру экрана, при переносе налево изображение зеркалится.

- Версия Service Worker и адрес его регистрации обновлены, чтобы браузер загружал новые интерфейсные и графические ресурсы.

## Версия 2.9.1 — расширенный поиск маршрутов и контекстный ИИ NPC

- NPC распознают больше естественных формулировок запроса пути: «где я», «куда идти», «как лучше добраться», «подскажи дорогу», «какие переходы рядом», «можно ли пройти» и названия всех локаций с падежными окончаниями.
- Маршрутные вопросы обрабатываются игровым графом переходов и не передаются внешней модели, чтобы NPC не выдумывали дороги. Вопросы вроде «где купить патроны» не считаются запросом маршрута.
- В историю каждой реплики добавлен ID собеседника: внешний ИИ получает только разговор с текущим NPC и не смешивает диалоги разных персонажей.
- AI-прокси привязан к localhost, ограничен списком разрешённых источников, имеет лимит запросов и не раскрывает API-ключ в браузере.
- Кеш Service Worker обновлён до v2.9.1.
