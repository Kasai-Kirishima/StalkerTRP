Встроенная музыка игры.

Положи сюда аудиофайлы MP3, M4A, OGG, WAV, FLAC или AAC. После добавления файлов выполни из корня проекта: npm run music:manifest

Скрипт создаст каталог встроенных композиций для КПК-плеера и базовых радиостанций, а также добавит найденные аудиофайлы в офлайн-кэш. Все композиции воспроизводятся локально, без внешних музыкальных сайтов.
